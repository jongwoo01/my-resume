# 사무직 이력서 사이트 템플릿

일반 사무직 취업을 위한 **개인 이력서 웹사이트 템플릿**입니다. 이력서의 필수 요건(역량·경력·학력·자격·스킬·활동·연락)을 모두 갖추면서, **직접 만든 AI 업무 자동화 툴**을 별도 섹션으로 보여줘 "스스로 업무 문제를 해결하는 지원자"로 포지셔닝합니다.

누구든 클론해서 `src/data/` 의 파일 두 개만 채우면 자신의 이력서 사이트가 됩니다. AI 코딩 에이전트(Claude Code, Codex 등)와 함께 채우도록 설계되어 있습니다.

> ⚠️ 들어 있는 인물 **홍길동**, 회사, 수치, 자격, 이메일, 스크린샷은 전부 **가상의 예시 데이터**입니다.

## 구성

```
[헤더] 이름 / 앵커 내비 / PDF 저장
1. 한 줄 소개와 대표 성과      (히어로 + 수치 4개)
2. 핵심 역량                   (3~5개, 수치·도구 근거)
3. 경력                        (최신순, 결과 → 행동 불릿)
4. AI 업무툴 포트폴리오        (카드 그리드 + 필터 → /tools/<slug> 상세 페이지)
5. 학력·자격·어학
6. 직무 스킬                   (활용 맥락과 함께)
7. 대외활동·수상
8. 연락                        (공개용 이메일, 근무 가능 지역)
```

툴 상세 페이지는 PRD 순서 그대로 6블록입니다: ① 업무 문제 → ② 결과물·스크린샷 → ③ 핵심 기능(≤3) → ④ 실수 방지를 위해 고려한 점 → ⑤ 도구·기간 → ⑥ 성과·라이브 링크. 스크린샷은 클릭하면 확대됩니다.

스택: Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · Pretendard. 무채색 팔레트, 애니메이션 없음, 라이브러리 최소.

## 시작하기

```bash
git clone <이 저장소> my-resume
cd my-resume
npm install
npm run dev
```

http://localhost:3000 에서 확인합니다.

## 내 이력서로 바꾸기

### 수정할 파일

| 파일 | 내용 |
|---|---|
| `src/data/resume.ts` | 이름·지원 직무·소개·대표 성과·핵심 역량·경력·학력·자격·스킬·활동·연락 |
| `src/data/tools.ts` | AI 업무툴 항목 (문제·결과·기능·고려점·도구·성과·링크·스크린샷) |
| `public/profile.svg` | 프로필 사진으로 교체 (정사각형 권장, `resume.ts`의 `profileImage` 경로도 수정) |
| `public/tools/<slug>/` | 툴 스크린샷 (16:10 권장, 데모 데이터만) |
| `src/app/icon.svg` | 파비콘 이니셜 두 글자 |

컴포넌트·스타일은 건드릴 필요가 없습니다.

### 에이전트와 함께 채우기

Claude Code 등 에이전트에 아래 프롬프트를 붙여넣고 본인 정보를 이어서 주세요.

```
이 저장소는 이력서 사이트 템플릿이야. 먼저 AGENTS.md를 읽어.
아래 내 이력 정보로 src/data/resume.ts 와 src/data/tools.ts 를 채워줘.

규칙:
- 날짜는 YYYY.MM, 최신순
- 성과는 결과를 먼저 쓰고 행동을 뒤에 (result → action)
- 회사명은 익명화 ("중견 제조업체 A사" 식)
- 휴대전화·생년월일·상세 주소·연봉은 절대 넣지 마
- 수치가 없는 성과는 지어내지 말고 나에게 되물어
- 디자인, 컴포넌트, 색은 바꾸지 마
- 끝나면 npm run lint && npm run build 로 확인해

내 정보:
(이름 / 지원 직무 / 경력 / 학력 / 자격 / 스킬 / 활동 / 공개용 이메일 / 근무 가능 지역 / 만든 업무툴 설명·수치·링크)
```

### PDF

헤더의 **PDF 저장** 버튼(또는 Cmd/Ctrl+P)을 누르면 화면에 보이는 그대로 브라우저에서 PDF로 저장됩니다. 내비·버튼 같은 조작 요소만 숨겨지고 나머지는 동일합니다. 브라우저가 찍는 날짜·URL 머리글/바닥글은 나오지 않게 처리되어 있습니다.

## 콘텐츠 작성 규칙

1. 성과에는 수치, 빈도, 기간 또는 처리 범위를 넣습니다.
2. 불릿은 결과를 먼저, 행동과 근거를 뒤에. `월 12시간 걸리던 정산 업무를 2시간으로 단축(83%↓) — 반복 계산을 함수와 매크로로 표준화`
3. 날짜는 `YYYY.MM`, 최신순.
4. 회사·고객 정보는 익명화.
5. 면접에서 설명할 수 없는 과장은 쓰지 않습니다.

## Vercel 배포

1. 저장소를 GitHub에 올립니다.
2. [vercel.com](https://vercel.com) → Add New Project → 저장소 가져오기. Next.js가 자동 감지됩니다. 설정 변경 없이 Deploy.
3. 발급된 `https://<project>.vercel.app` 에서 HTTPS로 열리는지 확인합니다.
4. `src/data/resume.ts`의 `siteUrl`을 그 주소로 바꾸고 다시 푸시합니다.
5. 맞춤 도메인은 Vercel 프로젝트 → Settings → Domains에서 추가하고, 화면에 안내되는 DNS 값을 그대로 설정합니다.
